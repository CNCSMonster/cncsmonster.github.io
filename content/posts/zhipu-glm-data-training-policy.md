## 一句话

智谱 GLM 的数据政策**不能笼统概括**，按产品分档区别对待：**团队版明确承诺"数据不用于训练"**；个人版和按量付费走通用条款，允许**脱敏后**用于模型训练，且无 opt-out。

---

## 一、三种产品是什么

| 产品 | 场景定义 |
|------|---------|
| **个人版 Coding Plan** | 个人开发者用 AI 编码工具写代码 |
| **团队版 Coding Plan** | 团队协作编码，企业场景 |
| **按量付费 API** | 自建应用、SaaS、网站、机器人等任何场景 |

> 📎 计费/额度/使用限制详见：[产品价格页](https://bigmodel.cn/pricing) / [套餐概览](https://docs.bigmodel.cn/cn/coding-plan/overview)

---

## 二、三种产品数据政策对比

| 政策维度 | 团队版 Coding Plan | 个人版 Coding Plan | 按量付费 API |
|----------|:-----------------:|:-----------------:|:------------:|
| **"不用于训练" 明确承诺** | ✅ 有 | ❌ 无 | ❌ 无 |
| 通用协议"优化产品服务" | ❌ 被专用条款覆盖 | 🟡 适用 | 🟡 适用 |
| 通用协议"永久不可撤销授权" | ❌ 被专用条款覆盖 | 🟡 适用 | 🟡 适用 |
| 隐私政策"脱敏数据训练" | ❌ 被专用条款覆盖 | 🟡 适用 | 🟡 适用 |
| **数据隔离** | ✅ 有资源隔离承诺 | 无明确承诺 | 无明确承诺 |

**效力层级**：

1. **专用条款优先**：团队版《团队套餐购买协议》明确将"数据默认不用于模型训练"列为套餐内容，且协议声明"官方公布的各项业务规范与正文具备相同的约束力"，因此该承诺**具有法律效力**，优先于通用用户协议
2. **通用条款兜底**：个人版和按量付费没有专用条款，完全受通用用户协议和隐私政策约束
3. **合同最优先**：企业可签署独立合同，在合同中约定数据使用条款（最高法律效力）

**注意事项**：团队版措辞是"**默认**不用于"，暗示可能存在例外情形（如用户主动授权）。

## 三、关键证据

### 3.1 团队版权益页（团队版专用）

> **"数据默认不用于模型训练 — 提交的代码、提示词、对话内容等不会用于模型训练，保护企业核心研发资产。"**

来源：[团队套餐权益页](https://docs.bigmodel.cn/cn/coding-plan/team)

这是智谱目前**唯一**明确承诺"不用于训练"的产品线。

### 3.2 通用用户协议（个人版/按量付费共享）

来源：[用户协议](https://docs.bigmodel.cn/cn/terms/user-agreement)

> *"除执行您的服务要求外，不会进行任何未获授权的使用及披露。"* ✅
>
> *"可能利用您使用...过程中产生的数据，**定位、维护和优化我们的产品和服务**。"* ⚠️
>
> *"您同意授予我方在全世界范围内**免费的、不可撤销的、永久有效的**使用、复制、修改、发行和展示该等数据的权利。"* 🔴

**解读**：

- Prompt 输入和模型调用数据可用于"优化产品和服务"（包括模型训练）
- 用户授予了**永久、不可撤销**的数据使用权
- 仅有"**另有约定**"（如企业合同）可豁免

### 3.3 通用隐私政策（个人版/按量付费共享）

来源：[隐私政策](https://docs.bigmodel.cn/cn/terms/privacy-policy)

> *"平台可能会对获取的信息开展脱敏研究以优化业务，这明确包含了**使用匿名数据进行机器学习或模型算法训练**。"* 🔴

**解读**：通用条款采用的是**"脱敏后可用"**立场 — 不是直接拿原始数据训练，但脱敏/匿名化处理后，平台保留用于模型训练的权利。

### 3.4 Z.ai 国际版隐私政策

⚠️ Z.ai 国际版**区分用户类型**：
- **API 客户（企业/开发者）**：明确声称"**不存储**用户内容"——"processed in real-time... not saved on our servers"
- **普通用户**：**会存储**——"We retain personal data for as long as it is needed... we retain it as long as you have an account"

这与国内版（bigmodel.cn）用户协议授权"永久不可撤销使用权"形成对比，但两者都针对普通用户。详见 [Z.ai 隐私政策](https://docs.z.ai/legal-agreement/privacy-policy)。

### 3.5 ZCode 隐私政策（zcode.z.ai）

ZCode 是智谱提供的编码应用，其隐私政策提到会使用数据来 **"train and improve our models"**（训练和改善模型），与国内版立场一致。

| **智谱 GLM/CodeGeeX** | ✅ 用于训练 | ❌ 基础版无 opt-out |

## 四、选用建议

### 决策场景

#### 场景 ①：我只想低价用 GLM 写代码

```
我是否在意数据被用于训练？
├── 不在意 → 个人版 Coding Plan（49元/月起，最便宜）
└── 在意   → 团队版 Coding Plan（标准版，有数据承诺）
              ⚠️ 但团队版 2席位起购，成本更高
```

#### 场景 ②：我是团队/企业，要协作编码

```
→ 团队版 Coding Plan（唯一选择）
   ✅ 数据不用于训练 + 组织管理 + IP白名单 + 超额按量
```

#### 场景 ③：我在自建应用里集成 GLM API

```
我是否在意数据被用于训练？
├── 不在意 → 按量付费 API（无工具限制，用多少付多少）
└── 在意   → ⚠️ 困境：
             按量付费 API 走通用条款，没有"不用于训练"承诺
             ↓
             可选方案：
             1. 联系智谱商务签企业合同，约定数据不用于训练
             2. 改用明确承诺不训练的其他厂商
             3. 使用 GLM 开源模型本地部署
```

### 快速决策表

| 你的情况 | 推荐产品 | 数据安全 | 月费参考 |

| 自建应用集成，不关心训练 | 按量付费 API | 🟡 脱敏后可能训练 | 按量 |
| 自建应用集成，在意训练 | 签合同 / 换别家 | 🟢 合同级保障 | 面议 |

## 五、隐私风险总结

1. **个人版和按量付费默认训练风险**：通用用户协议授予智谱永久、不可撤销的数据使用权，隐私政策允许脱敏后用于训练
2. **无 opt-out**：个人版用户无法选择退出数据训练
3. **条款模糊**："优化产品和服务"范围宽泛，无具体界定
4. **国际版/国内版差异**：Z.ai 国际版对 API 客户声称不存储，但对普通用户会存储；国内版对所有用户授权永久使用权
